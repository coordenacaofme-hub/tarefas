# Tarefas das Comissões — FME Aracruz

Planilha online para atribuir e acompanhar as tarefas da Coordenadoria Geral e das Comissões Permanentes do Fórum Municipal de Educação de Aracruz (Regimento Interno, Portaria SEMED nº 523/2026, arts. 18 a 22).

## Arquivos
- `index.html` — a página.
- `dados/tarefas.json` — **versão oficial** das tarefas e comissões.

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `fme-aracruz-tarefas`) e envie estes arquivos mantendo a pasta `dados/`.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)` e salve.
3. O endereço fica `https://SEU-USUARIO.github.io/fme-aracruz-tarefas/`.

## Atualizar as tarefas
1. Edite na página (as mudanças ficam salvas no seu navegador).
2. Clique em **Baixar tarefas.json**.
3. No GitHub: pasta `dados` → *Add file* → *Upload files* → envie o arquivo → *Commit changes*.

Obs.: repositório público deixa as tarefas visíveis a qualquer pessoa com o link. Não registre dados pessoais sensíveis (CPF, telefone etc.).
