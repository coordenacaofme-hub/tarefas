Como atualizar a planilha

A página é estática (GitHub Pages). A versão oficial é o arquivo dados/tarefas.json do repositório. Edições feitas aqui ficam só no seu navegador até serem publicadas.

  1. Edite as tarefas e comissões nesta página (clique em uma linha para abrir a ficha).
  2. Clique em Baixar tarefas.json.
  3. No GitHub, abra a pasta dados → Add file → Upload files, envie o arquivo baixado e confirme em Commit changes.
  4. Em 1 a 2 minutos a página publicada mostra a nova versão para todos.
